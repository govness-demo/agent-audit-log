# Agent audit-log plugin

Records every tool call an agent makes, with inputs, outputs and the person it acted for, in a tamper-evident log.

## Overview

A drop-in plugin that writes an append-only, hash-chained log of agent actions, so an administration can answer who did what, when and on whose behalf.
